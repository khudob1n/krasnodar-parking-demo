# Исследование публичных данных о парковках Краснодара

Дата исследования: 28.10.2026. Все выводы ниже либо проверены здесь, либо
явно помечены как предположение.

## Ограничения исследования

- Из облачного окружения разработки домены `parkingkrd.ru` и `krd.ru` закрыты
  сетевой политикой (прокси отвечает 403 на CONNECT). Портал из контейнера не
  открывался, браузерные запросы не перехватывались.
- Через внешний инструмент чтения страниц удалось открыть только оболочку
  портала (одностраничное приложение с заголовком «Городские парковки») и
  частично ответ `GET https://parkingkrd.ru/signingproxy/parkings`.
- krd.ru запрещает автоматическое чтение (robots), поэтому тексты
  постановлений сверены по вторичным публикациям. Это отмечено у каждого факта.
- Личные кабинеты, платёжные методы и закрытые API не использовались.
  Авторизация, CAPTCHA и ограничения доступа не обходились.

Название пути `signingproxy` может означать, что фронтенд портала подписывает
запросы к внутреннему API. Наш GET без подписи ответ получил, но это могло
измениться; импортёр при 401/403/429 и перенаправлениях останавливается и
ничего не обходит.

## Чего в данных нет

- Номер тарифной или территориальной зоны: поля нет ни у одной записи.
- Свободные места: значения есть, но это заглушка (1900-01-01).
- Статус работы парковки.
- Сводный действующий муниципальный перечень с датой редакции.
- Правила постоплаты и её сроки из первоисточника: коммерческие статьи
  пишут «до 23:59 следующего дня с 01.04.2026», первоисточник не найден.
  Поэтому постоплата не реализуется до проверки.
- Линии участков у 27 платных парковок (25 только с точкой, 2 без координат).
