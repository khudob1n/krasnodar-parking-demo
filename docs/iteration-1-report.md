# Итерация 1 — отчёт (28.10.2026)

## Сделано

- **Структура проекта**: `server/` (Go), `android/shared` (Kotlin
  Multiplatform, без android.* — готов к iOS), `android/app` (Compose),
  `data/` (сырые ответы, контрольные карточки, снимок), `schema/` (JSON
  Schema снимка), `docs/`. Подробно в [README](../README.md).
- **Исследование данных**: [docs/research/parkingkrd.md](research/parkingkrd.md).
  Публичный список: `GET https://parkingkrd.ru/signingproxy/parkings`, один
  ответ на 1716 записей без пагинации. Разобраны все 17 полей, найдены битые
  координаты (4 записи, две — в Бишкеке), заглушка вместо свободных мест,
  отсутствие тарифной зоны и статуса. Сверка с муниципальным актом № 6467 от
  09.10.2025 и двумя публикациями, несовпадения выписаны отдельно.
- **Схема данных**: [docs/data-model.md](data-model.md) и
  [schema/parkings.schema.json](../schema/parkings.schema.json). Номер портала,
  тарифная зона и тип хранятся раздельно; нет данных → `null`.
- **Импортёр** `server/cmd/importer`: из файла или с портала, сохраняет сырой
  ответ с sha256 и `.meta.json`, пишет `parkings.json`, `parkings.geojson`
  (с `source_url` и `fetched_at` в каждом объекте) и `validation-report.json`.
  Проверки: обязательные и новые поля, `totalLength`, дубликаты id и адресов,
  координаты в границах Краснодара, длина и удалённость участков, текст тарифа
  против полей, 19 контрольных карточек. Портал с 401/403/429 и
  перенаправлениями не обходится.
- **Сервер каталога** `server/cmd/server`: meta, полный каталог с ETag/304 и
  gzip, GeoJSON, карточка, поиск, ближайшие (только варианты).
- **Android**: три вкладки «Карта», «Гараж», «Профиль»; карта MapLibre с
  линиями участков (бледно-синие, выбранный — #0066FF) и точками площадок;
  переключатель карта/список; поиск по улице и номеру без сети; карточка
  парковки в порядке спецификации с «Нет данных», источником и датой; плашка
  «Нет сети / сервер недоступен» с повтором; скелетон загрузки; профиль
  «О данных». Офлайн: встроенный каталог из `data/snapshot` + последний
  каталог с сервера в памяти устройства, обновление по ETag при запуске и при
  появлении сети. Шрифт Onest (OFL) собран из официального пакета в TTF с
  кириллицей, латиницей и знаком ₽.
- **CI** `.github/workflows/ci.yml`: Go-тесты, проверка воспроизводимости
  снимка, сборка APK и unit-тесты Android.

## Проверено

| Что | Как | Результат |
| --- | --- | --- |
| Go: vet и тесты (portal, validate, snapshot/JSON Schema, api, importer) | `go vet ./... && go test ./...` | 20 тестов, все прошли |
| Импорт сохранённого ответа | `go run ./cmd/importer -input …` | 1716 парковок, 323 платные, 0 исключено, все блокирующие проверки и 19/19 карточек прошли |
| Воспроизводимость | повторный импорт с тем же `generated_at` | снимок побайтно тот же |
| Снимок против JSON Schema | `go test ./internal/snapshot` | соответствует; схема ловит «свободные места» без статуса |
| Сервер | запуск и `curl` meta, search, parkings (gzip 77 КБ) | отвечает |
| Kotlin shared | `./gradlew -PwithAndroid=false :shared:jvmTest` | 18 тестов, все прошли, включая чтение настоящего снимка |
| Шрифт | fontTools: 650 символов, кириллица, цифры, ₽ | есть |

**Не запускалось**: сборка APK, unit-тест `StatusTextTest` приложения,
экраны на эмуляторе, работа MapLibre. Причина — сетевая политика облачного
окружения закрывает `dl.google.com`, откуда берутся Android Gradle Plugin,
Compose и SDK (`Could not resolve com.android.tools.build:gradle:8.12.0`).
Код Android написан, но не скомпилирован: возможны ошибки сборки, которые
CI или первая локальная сборка покажут. Живой импорт с портала тоже не
выполнялся: закрыт `parkingkrd.ru`.

## Данных пока нет

- Номер тарифной или территориальной зоны — в ответе портала нет поля.
- Свободные места — в ответе заглушка с датой 1900-01-01.
- Статус работы парковки.
- Действующий сводный муниципальный перечень с датой редакции: krd.ru
  закрыт для чтения.
- Подтверждение, что `id` портала — это номер на табличке и в SMS.
- Правила и сроки постоплаты из первоисточника.
- Линии участков у 27 из 323 платных парковок.
- Базовая карта города для офлайна: выгрузки OSM из окружения недоступны
  ([docs/offline-map.md](offline-map.md)).
- Живая сверка снимка с порталом: снимок получен вручную, `verified_against_portal = false`.
