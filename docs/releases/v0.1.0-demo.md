**Демо-версия. Не официальный сервис города. Приложение не проводит платежи и не оплачивает муниципальную парковку.**

Первая итерация: каталог муниципальных парковок Краснодара на карте и в списке, поиск, карточка парковки, офлайн-просмотр.

## В этой версии

- Карта (MapLibre): линии участков и точки площадок из данных портала, без дорисовки.
- Список и поиск по улице или номеру, работают без сети.
- Карточка: номер из данных портала, адрес, тариф, свободные места, платное время, вместимость, тарифная зона, источник и дата. Нет значения — «Нет данных».
- Встроенный каталог: 1716 записей (323 платные) из ответа `parkingkrd.ru/signingproxy/parkings`, полученного 28.10.2026 и не сверенного с порталом автоматически.
- Вкладки «Карта», «Гараж», «Профиль»; в профиле — «О данных».

## Ограничения

- «Припарковаться» пока неактивна: сценарий оплаты — в следующей версии.
- Базовая карта города не встроена: на фоне показаны только парковки.
- Свободных мест и тарифных зон в источнике нет.
- APK подписан debug-ключом сборочной машины: для установки вручную, не для магазина.
